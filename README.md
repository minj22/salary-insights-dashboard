# Developer Salary Intelligence

An interactive analytics dashboard exploring developer salaries, job satisfaction, and employment trends using Stack Overflow Developer Survey data.

## Features

- **Exploratory Data Analysis:** Job satisfaction and salary trends across developer roles and age groups.
- **Remote vs. Hybrid:** Salary comparisons using t-tests, bootstrap analysis, confidence intervals, and median tests.
- **Education Analysis:** Salary differences across education levels using ANOVA and bootstrap methods.
- **Interactive Visualizations:** Dynamic charts and statistical insights.

## Tech Stack

- Python
- Streamlit
- Plotly
- NumPy, Pandas, SciPy

## Data Privacy

The dashboard uses aggregated statistical data rather than individual survey responses.
